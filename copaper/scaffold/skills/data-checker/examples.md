### Example 5: Data Inconsistency

```
<!-- AI Comments: 
**AI-GENERATED DATA CHECK ANALYSIS - FOR AUTHOR REVIEW**

[DATA ISSUE TYPE]
Data Inconsistency: Same Metric Different Values

[LOCATION]

     - "On dataset A: 92.1%"
     - "On dataset B: 91.8%"
     
3. Ensure reproduction scripts match

[VERIFICATION STEPS]
1. Check all mentions of detection rate in paper
2. Verify each has correct value for its context
3. Run reproduction scripts for each table
4. Ensure consistency throughout paper
5. Re-run this checker to verify consistency
